01. PYTHON

Python là ngôn ngữ lập trình bậc cao, có cú pháp đơn giản và dễ học đối với người mới bắt đầu.

Kiến thức: Biến, vòng lặp, hàm, list, dictionary và xử lý dữ liệu.

Ứng dụng: AI, tự động hóa, phân tích dữ liệu.

☕

02. JAVA

Java là ngôn ngữ lập trình hướng đối tượng, được sử dụng trong nhiều hệ thống phần mềm.

Kiến thức: Class, Object, Method, Constructor và kế thừa.

Ứng dụng: Phần mềm doanh nghiệp, ứng dụng Android và hệ thống máy chủ.

🤖

03. TRÍ TUỆ NHÂN TẠO AI

AI là công nghệ giúp máy tính thực hiện những nhiệm vụ cần khả năng phân tích, nhận dạng và xử lý thông tin.

Kiến thức: Machine Learning, Deep Learning và Generative AI.

Công cụ: ChatGPT, Gemini, Claude.

🧠

04. PHÉP THỬ TURING

Phép thử Turing được Alan Turing đề xuất năm 1950 nhằm thảo luận khả năng máy móc thể hiện hành vi hội thoại giống con người.

Kiến thức: Imitation Game, trí thông minh nhân tạo và triết học AI.

Ý nghĩa: Đặt ra câu hỏi về khả năng giao tiếp thông minh của máy tính.

🌐

05. GIT & GITHUB

Git là công cụ quản lý phiên bản mã nguồn. GitHub là nền tảng lưu trữ dự án trực tuyến.

Kiến thức: Repository, Commit, Push, Pull và Branch.

Ứng dụng: Quản lý dự án, làm việc nhóm và lưu trữ code.

📊

06. MICROSOFT EXCEL

Excel là phần mềm bảng tính giúp người dùng tổ chức, xử lý và phân tích dữ liệu.

Kiến thức: SUM, AVERAGE, IF, COUNTIF, VLOOKUP.

Ứng dụng: Quản lý điểm số, thống kê và lập bảng dữ liệu.

📝

07. MICROSOFT WORD

Word là phần mềm soạn thảo văn bản, hỗ trợ tạo báo cáo, tài liệu và luận văn.

Kiến thức: Heading, Table, Header, Footer và Table of Contents.

Ứng dụng: Làm báo cáo học tập, bài tập và tài liệu chuyên môn.

🎨

08. HTML & CSS

HTML tạo cấu trúc nội dung website, CSS giúp thiết kế giao diện và bố cục.

Kiến thức: HTML Tags, CSS Selectors, Flexbox và Grid.

Ứng dụng: Thiết kế website, trang cá nhân và giao diện web.
